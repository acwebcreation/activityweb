Comment ça marche ?

  1. 1
    Un client vous achète un bon cadeau

    En caisse, par téléphone ou par message. Vous encaissez comme d'habitude (espèces, Bancontact, virement). Votre client ne passe jamais par ce site.

  2. 2
    Vous créez le bon ici, en 1 minute

    Montant ou prestation, pour qui, de la part de qui, un petit message. Vous obtenez un PDF à votre nom, numéroté, avec un code unique : imprimez-le ou envoyez-le par email ou WhatsApp.

  3. 3
    Le jour où la personne vient avec son bon

    Ouvrez le Registre, tapez le code ou le nom, cliquez sur Utiliser. Le bon est marqué comme utilisé : impossible de s'en servir deux fois. S'il n'est utilisé qu'en partie, le solde restant est noté.

  4. 4
    Vos données restent chez vous

    Tout est enregistré sur cet appareil, dans ce navigateur : personne d'autre n'y a accès, pas même ActivityWeb. Exportez une sauvegarde de temps en temps (onglet Réglages) pour ne rien perdre et pour passer sur un autre appareil.
